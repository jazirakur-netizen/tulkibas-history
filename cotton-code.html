Жазалау шараларын анықта

Тізімнен мәтінде аталған төрт жазалау және мәжбүрлеу шарасын таңда:
  1. Айыппұл салу.
  2. Ерікті оқу курсына жіберу.
  3. Мал-мүлікті тәркілеу.
  4. Қоныс аударту.
  5. Медальмен марапаттау.
  6. Бас бостандығынан айыру.

Код ережесі: Дұрыс жауаптардың нөмірлерін өсу ретімен қатар жаз.

  1. Орта шаруалар мен кедейлер де сотталған.
  2. Тәркілеу кезінде тек мақта ғана алынған.
  3. Мақтаны кешіктіріп тапсырған артельдерге де айыппұл салынған.
  4. Сырдария округінде бір ғана учаскелік халық соты жұмыс істеген.

Код ережесі: Дұрыс тұжырымға 1, бұрыс тұжырымға 0 жаз. Тұжырымдардың ретін сақта.

Мұрағаттағы қайшылық

Код ережесі: Айырманы есептеп, төрт таңбамен жаз.
